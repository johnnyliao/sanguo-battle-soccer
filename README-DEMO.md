# 三國亂鬥足球 Roblox Demo

5 對 5 亂鬥足球（規則與網頁版相同，伺服器每秒 60 tick），方塊造型、無美術、無音效。

## 開啟方式

1. 安裝 Roblox Studio，開啟檔案 `build/sanguo-demo.rbxlx`。
   （若檔案不存在：`npx rbxtsc` 後執行 `rojo build default.project.json -o build/sanguo-demo.rbxlx`）
2. 單人：按 **Play**（F5）。雙人：**Test → Clients and Servers → Start**，Players 設為 2。
3. 第一位玩家在畫面選 魏／蜀／吳，對手國家隨機。第二位玩家自動操控對手隊的前鋒（FW）；第三位以後只能觀戰。其餘球員由 AI 操控。
4. 比賽結束顯示結果 5 秒，之後以相同國家重新開賽。

## 操作

| 動作 | 鍵盤 | 手把 | 手機 |
| --- | --- | --- | --- |
| 移動 | WASD / 方向鍵 | 左搖桿 | 左半邊拖曳虛擬搖桿 |
| 衝刺 | Shift 或連按方向 | RB | 搖桿推到最外緣 |
| 攻擊／射門（按住蓄力） | J | A | 「攻擊射門」大按鈕 |
| 傳球／叫球 | K | X | 「傳球叫球」 |
| 大招 | L | Y | 「大招」（顯示冷卻秒數） |

你操控的球員頭上有黃色 ▼；只顯示己方球員的體力條。

## 已知限制

- 只有方塊與簡單圓盤／圓環特效，沒有角色美術、動畫與音效。
- 加時 PK 大戰沒有操作介面：進入 PK 時由 AI 自動替雙方踢完，畫面只顯示 PK 比分提示與結果。
- 隊伍選擇只有「選國家」；沒有選角色、陣型或比賽時間設定（上下半場各 120 秒）。
- 中途加入的玩家看不到加入前已開始的範圍特效（冰雨、法陣等），之後的新特效正常。
- 未在 Roblox Studio 實機驗證（開發環境為 Linux，只驗證過編譯、rojo 建置與 Lune 單元測試）；若有視覺或操作問題請回報。
