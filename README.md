# 三國戰鬥足球｜主公裝備設計

這份設計接續 Roblox 版 R3 主公養成。主公在營帳選流派、武器與大招。流派決定場上位置、成長與被動，武器決定普攻的距離、節奏與風險，大招提供該流派的戰術選項。打贏具名魔王後可同時取得武器、習得大招並收服武將。

## 現況與設計範圍

- P1／P2 已有三個流派、營帳、裝備背包、舊存檔轉換與出戰站位。實際存檔的 `loadout` 有 `weapon` 與 `special`，位置由 `lordClass` 與隊形決定。小隊缺少對應位置時沿用既有站位回退。
- 目前可裝備三件新手武器、三個新手大招。武將 ID 已可存進裝備背包，武將武器和大招的裝備門檻仍待 P3／P4 開放。現有結算已能收服武將。
- 首版沿用兩格裝備與固定首勝獎勵。裝備差異先從普攻手感和戰術用途做起，強化、詞綴、套裝與額外欄位留到這套玩法經過試玩後再評估。

## 武器與流派

武器跨流派可裝備。沿用目前偏好類型全能力 +1、單項上限 10 的規則。首版同類兵器共用普攻設定，以名稱、圖示和手持模型區分。新手兵器與掉落兵器共享類型規則，玩家可以因戰術需要繼續使用初始裝備。

| 武器類型 | 代表裝備 | 普攻定位 | 交換條件 |
| --- | --- | --- | --- |
| 劍 | 天子劍、曹操／孫權／周瑜武器 | 近身出手快，適合禁區干擾 | 接觸距離短 |
| 長兵 | 破陣槍、青龍刀、趙雲／張飛／馬超武器 | 從正面較遠距離攔截持球者 | 側面覆蓋較窄，揮空容易被繞 |
| 扇 | 鳳翼扇、諸葛亮／司馬懿／大喬／小喬／甄姬武器 | 沿用扇類普攻，適合中場牽制 | 保留既有出手節奏和距離；甄姬首版共用扇類判定 |
| 重兵 | 許褚狼牙棒、孫策大錘、張遼雙斧 | 建議新增前方寬弧擊退，適合封路 | 前搖與收招最長，對手可閃避；普攻不額外縮短大招冷卻 |

前三類以現行判定和手感為起點。重兵首版沿用既有命中、掉球與擊倒規則，先調前方覆蓋與出收招時間。猛將的擊倒減冷卻仍由「破陣」處理，每次有效擊倒只計一次。

| 流派 | 新手組合 | 可嘗試的換裝 |
| --- | --- | --- |
| 猛將／前鋒 | 破陣槍＋龍騰 | 換重兵壓迫對手，代價是失去長兵的正面觸及距離 |
| 軍師／中場 | 鳳翼扇＋羽風陣 | 保留扇類牽制，換中場池的大招改變戰術用途 |
| 鐵壁／後衛 | 天子劍＋旋風斬 | 在快速近身的劍與收招較慢的重兵間選擇，也可換後衛池大招 |

大招沿用 `classPool`。武器與大招分開驗證，換武器後仍可施放目前流派允許的大招。例如鐵壁可用天子劍普攻，另裝關羽的大招。守門員來源大招若有專用站位、球權或 AI 條件，先定義後衛主公的施放條件，再逐招開放裝備。

## 取得、換裝與出戰

1. **首勝**。伺服器依故事關卡的 `bossCharId` 發放對應武器和大招，收服沿用 `stage.recruit`。同一次 profile 更新記錄通關、裝備及收服。每項所有權獨立去重，結算只顯示本次新增項目。無具名魔王的關卡沿用既有獎勵。
2. **舊存檔**。從 `cleared` 的已通關關卡查出具名魔王，登入整理存檔時補齊缺少的武器與大招。依玩家的故事路線解析關卡，不以已招募名單推算，避免初始武將被誤判為首勝。既有裝備選擇依正常合法性規則處理，補發本身不自動換裝。若資料載入失敗並進入唯讀模式，沿用現有保護。
3. **營帳**。顯示目前有效裝備、武器類型、能力差與可用流派。已取得但尚未開放或流派不符的大招顯示原因。建議把流派切換改成保留仍合法的武器與大招，只將不合適的大招換成新流派初始招式。
4. **開賽**。沿用伺服器的 `equip` 指令，驗證裝備欄位、已持有、功能已開放、大招池與比賽狀態。開賽由伺服器解析有效裝備，建立該場用的角色設定。場上行為、手持模型、技能圖示和名稱都讀同一份出戰設定。

## 實作順序

| 階段 | 改動 | 完成條件 |
| --- | --- | --- |
| P3 大招通用化 | 在 [loadout.ts](roblox/src/shared/loadout.ts) 將大招 ID 解析成技能設定與圖示鍵。[teamBuilder.ts](roblox/src/shared/teamBuilder.ts) 把技能設定交給模擬端，客戶端以招式識別鍵選特效，角色 ID 只用於角色外觀。技能效果依 `special.mode` 執行，若同 mode 共用不同行為外觀，另由技能識別鍵選素材。 | 用主公施放一個武將招式，確認施放條件、命中、音效、坐騎或道具掛點和冷卻圖示一致，再放行其餘已驗證大招。 |
| P4 武器裝備化 | 在 `loadout.ts` 集中定義裝備 ID、名稱、類型、普攻設定與素材鍵。擴充戰鬥層的普攻類型以支援重兵；舊 `LordWeapon` 值及相容指令仍維持劍／槍／扇。營帳與 `lordDef` 共用同一份有效武器及能力值計算。 | 每把武器可解析至一個類型，主公實際普攻與營帳預覽一致；第 4 批現有武器圖示可沿用，手持模型依裝備鍵查找。 |
| P5 首勝獎勵 | 在 [match.server.ts](roblox/src/server/match.server.ts) 的 `finishStory` 補上武器、大招獎勵，擴充 `StoryResult` 和 [lootUi.ts](roblox/src/client/lootUi.ts)。在 [profile.ts](roblox/src/server/profile.ts) 的存檔整理路徑補發歷史獎勵，沿用 `owned.weapons[]`、`owned.specials[]`。 | 首勝有新獎勵、敗場不發、重打不重複發；舊玩家可登入補領，原有 XP、金幣與收服流程照常。 |
| P6 平衡與驗收 | 以三流派 × 四武器類型跑相同場景，記錄搶球成功率、揮空後被反擊率、大招施放間隔及進球率。比較同流派新手武器與魔王掉落的表現。 | 原 15 將 golden 通過；Studio 驗證桌面與手機的換裝、獲獎、重登、位置回退及快捷比賽。 |

可先用一場關羽首勝串完整流程。取得青龍刀與大招、收服關羽後，在猛將營帳裝青龍刀，確認長兵普攻與偏好加成。切到鐵壁後裝關羽大招，在下一場確認技能表現與營帳一致，再重打同關驗證獎勵去重。
