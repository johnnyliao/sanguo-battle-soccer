# 三國戰鬥足球：搬到 Roblox ＋ 等級 RPG 規劃（2026-11-24 草案）

## 一、搬到 Roblox

### 1. 總方向（建議）
- **規則程式盡量沿用，不重寫**：現在的 `src/sim`（比賽規則、所有大招）是純 TypeScript，不依賴瀏覽器。Roblox 用 Luau 語言，但有 **roblox-ts**（把 TypeScript 編譯成 Luau 的工具），理論上可以直接編譯過去，網頁版和 Roblox 版共用同一份規則。第一步先做「可行性試驗」確認。
- **伺服器說了算**：Roblox 天生是線上多人，比賽規則在 Roblox 伺服器上跑（60Hz），玩家只送按鍵，畫面由各自的手機／電腦畫。這正好對應我們原本「邏輯與畫面分離、AI 只送虛擬按鍵」的設計，連線那一塊等於 Roblox 幫我們做了。
- **美術先沿用 2D 角色圖**：在 3D 場景裡用「看板」（BillboardGui／SurfaceGui 的貼圖，換格播放動畫）放現有的角色圖與特效，鏡頭固定斜側視角，看起來跟現在一樣是 2.5D。之後如果要更像 Roblox 風格，再換 3D 模型。
- **5v5 真人對戰＋AI 補位**：Roblox 本身有伺服器、配對、好友組隊，缺人時用現有 AI 補。

### 2. 需要你準備的
- Roblox 帳號、一個 Roblox 群組（遊戲掛在群組下，之後收益與共同開發比較方便）。
- **Roblox Studio 只能裝在 Windows／Mac**：122 是 Linux，跑不了 Studio。做法是程式放在 122，用 **Rojo**（把檔案即時同步進 Studio 的工具）讓筆電上的 Studio 連到 122。筆電只負責開 Studio 試玩，重的編譯和測試都在 122。
- 自動化：Roblox **Open Cloud** API 金鑰（可以從 122 直接發佈遊戲版本、跑伺服器端測試腳本），之後設定。

### 3. 要注意的限制
- **圖片上傳**：Roblox 單張圖片上限 1024×1024，我們的角色圖、特效圖要重新切成小張；每張圖都要過 Roblox 審核。
- **音效上傳**：33 個音效是 CC0，可以上傳，但每月上傳數量有上限，也要過審核。
- **內容分級**：要填 Roblox 的內容問卷。卡通打鬥、擊飛屬於輕度暴力，一般可以。
- **付費隨機獎勵（抽卡）**：Roblox 規定花錢抽的東西要公開機率，對未成年玩家也越來越嚴。建議**不做付費抽卡**，武將和造型都用遊戲內貨幣或任務解鎖。
- **網路延遲**：近身打鬥對延遲很敏感，自己角色的移動要在本機先動（預測），伺服器再校正，否則手感會黏。

### 4. 分階段
| 階段 | 內容 | 完成條件 |
|---|---|---|
| R0 可行性試驗 | roblox-ts 編譯 `src/sim`；在 Roblox 伺服器上跑一場 AI 對 AI，結果跟網頁版一致 | 同樣的種子與輸入，兩邊比分與事件一致 |
| R1 單人可玩 | 斜側鏡頭、2D 看板角色、球、球門、手機搖桿與按鈕、1 真人 vs AI | 在 Studio 和手機上能打完一場 |
| R2 多人 | 大廳、組隊、配對，5v5 真人＋AI 補位，本機預測移動 | 兩支手機同場對戰不卡 |
| R3 存檔與 RPG 第一版 | 帳號等級、武將等級、貨幣、每日任務（見第二部分） | 退出再進來進度還在 |
| R4 上架測試 | 內容問卷、圖示與介紹、小規模公開測試、看數據調整 | 開放公開 |

網頁版保留當成「快速試玩與測規則」的地方，兩邊共用規則程式。

## 二、等級 RPG 要素（增加黏著度）

### 原則
- **對戰公平**：等級不能讓真人對戰變成「課金或練等就贏」。成長給「更多選擇、更好看、更有成就感」，不直接加大量數值。
- **每次上線都有事做**：短目標（每日任務）＋中目標（武將升級、解鎖）＋長目標（官職排名、收集全武將）。

### 1. 帳號等級（主公等級）
- 每場比賽給經驗：出場、進球、助攻、擊倒、勝利、完成任務。
- 升級解鎖：新模式、新武將欄位、頭像框、稱號。

### 2. 武將等級與「兵法」
- 每位武將各自升級（例如 1～30 級），用他出場越多升越快。
- 升級**主要給造型與兵法**，而不是大量加能力值：
  - 第 5／15／25 級：武將造型（換色、新兵器外觀、大招特效換色）。
  - **兵法欄**（可裝 1～3 個小被動，彼此取捨）：例如「起身快 0.2 秒」「大招冷卻 −1 秒但耗體力 +5」「衝刺耗體力 −10%」。效果都很小、有代價。
- **排位賽關掉兵法或全部統一**，休閒賽和劇情關才有效果，保證排位公平。

### 3. 收集武將
- 現有 15 位一開始開放每國 2～3 位，其餘用遊戲內貨幣或劇情關解鎖。
- 未入選的武將（典韋、甘寧、太史慈、黃蓋、呂布、黃忠、夏侯惇、陸遜……）當後續新角色，一次推一位，每次更新都有新東西。
- 自組隊伍：不再限定同國，可以混搭（另設「同國羈絆」小加成，只在休閒與劇情）。

### 4. 劇情關（PvE）
- 用現有 AI 做三國故事關卡：黃巾之亂、虎牢關（對上呂布王隊）、長坂坡、赤壁之戰……
- 每關有特殊規則（例如「赤壁：場上隨機起火」「虎牢關：呂布體力三倍」），給大量經驗與解鎖。
- 一個人也能玩，是新玩家留下來的主要內容。

### 5. 每日／每週
- 每日任務 3 個（例如「用吳國武將進 2 球」「放 5 次大招」），每週任務較大。
- 連續登入獎勵；週末活動（雙倍經驗、特殊規則賽）。

### 6. 排位與官職
- 排位賽分段用官職命名：伍長 → 什長 → 校尉 → 中郎將 → 將軍 → 大都督。
- 每季（約 6～8 週）重置一部分，給季末獎勵（限定頭像框、稱號）。

### 7. 勢力戰
- 玩家加入魏／蜀／吳其中一個勢力，每週統計各勢力總勝場，贏的勢力全員領獎勵。讓玩家有歸屬感、拉朋友一起玩。

### 8. 收益（Roblox 內）
- 只賣**不影響勝負**的東西：造型、特效換色、表情動作、進球慶祝動作、戰令（每季的免費＋付費獎勵路線，付費線只多造型）。
- 可選：VIP 通行證（經驗 +20%、專屬稱號）——只加快進度，不加戰力。
- Roblox Premium 玩家遊玩時間也會給開發者分潤，黏著度本身就是收益。

### RPG 存檔資料（R3 要做的）
- 帳號：等級、經驗、貨幣、已解鎖武將、造型、任務進度、登入紀錄、排位分數。
- 武將：每位的等級、經驗、裝備的兵法與造型。
- 用 Roblox DataStore 存，每場結束與離開時寫入，加版本號方便之後改格式。

## 三、建議的第一步
1. **R0 可行性試驗**（最重要，決定整個做法）：在 122 裝 roblox-ts 與 Rojo，試編譯 `src/sim`，列出不相容的地方與要改多少。
2. 同時用網頁版先做 RPG 的「帳號等級＋每日任務＋武將等級」原型（存在瀏覽器），先驗證好不好玩，再搬進 Roblox。
