# 三國戰鬥足球 美術需求清單（給出圖 AI／美術）

更新：2026-11-27

這是一款 Roblox 上的三國武將亂鬥足球遊戲。玩家用自己的 Roblox 角色當「主公」，帶著關羽、曹操等名將踢球打怪。3D 角色已經做好，這份清單**只需要 2D 美術**：介面、頭像、圖示、商店宣傳圖。目標玩家是 8～12 歲的小學生。

---

## 一、怎麼交圖（重要）

1. 照下面每張表的**檔名**存成 PNG。
2. 放進這個 repo 的資料夾：
   - 第 1 批 → `art/incoming/batch1/`
   - 第 2 批 → `art/incoming/batch2/`
   - 第 3 批 → `art/incoming/batch3/`
3. **推到 `art-delivery` 分支**（不要直接推 `main`），開發者檢查後會合併並放進遊戲。
4. 有問題就在同一個資料夾放一個 `QUESTIONS.md` 寫下來。
5. 有圖層的原始檔（PSD／Procreate／Figma）放 `art/source/`，方便之後改色。

---

## 二、共通規格

- **畫風**：照下方「角色參考圖」：明亮 Q 版卡通（頭身比約 1:2～1:3）、粗外框、高飽和、日系手遊感；要「帥又可愛」，不要寫實、不要血腥。
- **陣營配色**：魏＝藍 `#2F6FD8`、蜀＝綠 `#2FA84F`、吳＝紅 `#D83A3A`、黃巾軍＝黃 `#E8B923`；金色 `#F5C542` 當強調色（勝利、傳說、按鈕框）。
- **格式**：PNG，透明背景（商店縮圖和背景圖除外）。
- **尺寸上限**：Roblox 單張圖最大 1024×1024，超過會被縮小。下表寫 1920×1080 的背景圖，請另外交一份縮成 1024 寬的版本。
- **文字**：除了 Logo 和結算標題字，圖上**不要放文字**（文字由遊戲程式顯示）。
- **命名**：英文小寫＋底線，例如 `portrait_guanyu.png`。
- **原創**：所有角色、Logo、介面都要原創，不能描摹或模仿任何現有遊戲（包括其他三國遊戲）的造型和介面。
